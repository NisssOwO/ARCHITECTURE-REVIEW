# 筑忆：建筑理论复习网页

这是一个纯静态、离线优先的建筑理论复习网页。它不需要 npm、开发服务器或构建工具，直接打开 `index.html` 即可使用。

## 使用

1. 双击打开 `index.html`。
2. 进入左侧“资料浏览”。
3. 点击“导入资料”。
4. 选择 `F:\work\fuxi\zl` 文件夹。
5. 等待网页读取 Markdown 并生成知识点卡片。

Chrome 或 Edge 的桌面端支持选择文件夹。手机端可以逐步选择 Markdown 文件；手机无法直接访问电脑的 `F:` 盘。

## 当前功能

- 四科总览和学习状态样式；
- Markdown 文件夹导入；
- 标题、重点和次重点解析；
- 知识点卡片浏览；
- 科目筛选和关键词搜索；
- 收藏和加入复习；
- “复习”和“浏览卡片”两种模式；
- 按科目、书目文件和章节选择复习范围；
- 左右按钮、键盘和触摸滑动切换卡片；
- 复习模式隐藏答案，浏览模式直接显示答案；
- 夜间模式界面；
- IndexedDB 本地保存，localStorage 回退；
- JSON 备份；
- Anki TSV 导出；
- Anki 导入准备说明和示例文件（见 `ANKI_PREP.md`、`anki-sample.tsv`）；
- 手机端响应式布局。

## 数据位置

资料和复习记录保存在当前浏览器的本地存储中。原始 Markdown 文件不会被网页修改。

更换浏览器或清理浏览器数据前，请在“设置”中导出 JSON 备份。

## Anki 导出

进入“知识卡片”，点击“导出 Anki TSV”，然后在 Anki 中选择制表符分隔文本导入：

- 第一列：卡片正面；
- 第二列：卡片背面；
- 第三列：标签。

## 当前限制

- 不包含图片识别、图片遮挡卡和语音功能；
- 不包含 AI 批改和云端同步；
- 资料更新后需要重新导入；
- 当前导入解析以重点条目为主，复杂嵌套条目仍需继续优化。
